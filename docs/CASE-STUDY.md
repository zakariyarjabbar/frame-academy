# FRAME ACADEMY — agency case-study draft

FRAME ACADEMY is a self-initiated portfolio concept for a focused photography and filmmaking academy. The design pairs cinematic portraiture and bold condensed type with quiet learning workspaces. Charcoal surfaces keep attention on photographic work; a small yellow accent identifies actions, progress and selected states.

The demo contains six compact courses, each with an original one-minute visual lesson, an illustrated reading, a guided practice and a five-question quiz. The product journey moves from course discovery through a simulated enrollment into a working player, timestamped notes, practice reflection, assessment and a downloadable demo certificate.

The implementation uses Next.js App Router and a complete static export. Bundled content supplies the catalog and lessons; a single versioned browser store handles learner records. Duplicate enrollment preserves its original receipt, quiz retries keep earlier achievements, and certificate issuance requires all lesson and assessment conditions. Storage errors offer an explicit temporary session rather than claiming a failed write succeeded.

The project demonstrates visual direction and frontend learning workflows without a database, payment integration or external login. Original generated imagery, fictional instructor personas and clear demo disclosures keep the concept honest. Local tests cover static routing, media playback, state transitions, accessibility checks and desktop/mobile layouts. No real client engagement, student results, accreditation or commercial outcomes are claimed.
